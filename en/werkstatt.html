Workshop Packages

Printable sheets for the books — each book has its own package.

The books of the Digital Sovereignty series come with sheets to print: checklists, fill-in forms, letter templates, logs. They are kept separate per book so you only download what belongs to yours. All free, no sign-up, with a checksum per file. Pick your book:

Book 1 · GrapheneOS: Android in the Age of Surveillance

Five principle sheets without menu paths: Installation Checklist, My App Strategy, User Profile Plan, Travel OpSec Checklist, Emergency Sheet "Phone Gone".

Book 1 package

Book 2 · Digital Sovereignty: The Complete System

Four templates: GDPR Letters to Data Brokers, Residents' Register Blocks application with ePA objection, Network Zone Plan, Emergency Sheet Password Manager.

Book 2 package

Book 4 · Your Own Bank: Master Bitcoin Self-Custody

Ten sheets plus two offline tools: dice logs, passphrase sheet, restore drill, signature anchor, multisig and heirs guides, check-day calendar.

Book 4 package

For custody, backups and inheritance, Book 3 The Decentralized System points to the Book 4 package and will get its own package later.

What all packages share

Single-page A4, Alien Investor style, chapter reference on the sheet, license CC BY-SA 4.0. No sheet holds a secret: no seeds, no passwords, no codes, locations as abbreviations only. Each package has a ZIP file with a checksum and a table with the checksum per sheet. The books themselves are on the books page.
